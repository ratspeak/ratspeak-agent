# Security

Report suspected vulnerabilities privately to
[mail@ratspeak.org](mailto:mail@ratspeak.org), or use
[GitHub private reporting](https://github.com/ratspeak/ratspeak-agent/security/advisories/new)
when available. Do not open a public issue for a security report.

Include the platform (macOS, Windows, Linux, or Raspberry Pi OS), app or Pi
runtime version/commit, reproduction steps, and impact. Use test identities and
redacted logs—never include private keys, `identity.seed` files, Venice or
Hermes API keys, Wi-Fi passwords, pairing secrets, or message databases.
